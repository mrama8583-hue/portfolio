# Rama Mahmoud - Portfolio

# Description

A personal, fully responsive portfolio website designed to showcase my web development skills, educational background, and recent projects. It serves as my digital resume and a centralized place to reach me.

# Technologies Used

- HTML
- CSS
- JavaScript

# Main Sections & Features

- **Dark/Light Mode Toggle:** An interactive feature that allows users to switch between themes for a better viewing experience.
- **Responsive Design:** Ensures the website looks great on mobile phones, tablets, and desktop screens.
- **Home:** A quick introduction and profile overview.
- **About Me:** Information about my background and my CIS studies at Al-Albayt University.
- **Skills:** A visual list of my technical toolkit (HTML, CSS, JS, React, Tailwind, Git).
- **Projects:** A structured gallery of my recent coding projects with direct links.
- **Contact:** Quick access to my GitHub, LinkedIn, and Email.
